# 0068：补全并导入 40 条精选知识

Status: ready-for-human

## 目标与范围

按用户要求，将 [0067 选出的 40 条知识](../docs/knowledge-list.selected.json) 补全后写入默认个人库 `.local/concept-discovery.sqlite`。产品依据为 [需求文档](../docs/需求文档.md) 的广义 Concept 内容要求及 [产品设计文档](../docs/产品设计文档.md) 的双语文章与关系设计。

用户已授权补全内容和写入数据库。本任务保留原始清单，产出独立补全稿及来源研究记录。每条补全中英文定义、别名、触发场景、诊断问题、说明性示例、边界、行动步骤、Agent 指引、出处与阅读正文；配图可空。

## 验收条件

- 40 个入选 ID 全部覆盖，无占位出处，双语字段与阅读正文齐备；逐条记录实际访问的来源及纠正点。
- 已存在 ID 原位补全，已有文章、图片和历史修订保留；其他 Concept 内容不变。
- 导入先在副本预演，正式写入前创建可恢复 SQLite 快照；通过 Registry 校验并保持修订语义，失败不留下部分写入，重复执行不产生重复条目或文章。
- 实际数据库中的 40 条双语可浏览、可推荐，正文和关联可读取；SQLite 完整性与外键检查通过。
- 执行导入回归测试、`npm run check`、实际数据库审计，并验证 Web 中的中文及英文详情。

## 工作分工与进度

- 主 Agent：任务状态、合并补全稿、重复核对、导入脚本及测试、备份与实际数据库验证。
- research 技能要求后台研究，最初将内容分成三个独立子任务。后台 Agent 遇到用量限制，未留下内容文件；主 Agent 接手来源核对并分批完成全部 40 条。长中文 Python stdin 曾发生编码错误，改用文件写入后成功；未将失败的草稿计为完成。
- 写入前数据库有 27 条；重合 ID 为 `falsifiability`、`first-principles`、`inversion`、`redundancy-backup`、`second-order-thinking`、`six-thinking-hats`。实际新增 34 条、补全 6 条，总数 61 条，新增 37 条双语解释关系。
- 完整资料见 [补全稿](../docs/knowledge-list.completed.json)，逐条来源、阅读范围和修正说明见 [研究记录](../docs/knowledge-curation/0068-sources.md)。全部 40 条有双语正文、问题、示例、边界、步骤和 Agent 指引。

## 决策与未决事项

- 以实际数据库为准，不将旧任务的内容完整性描述当作当前证据。
- 补全稿纠正定义和归属；已有文章作为既有资料保留，新的核实说明追加到文章末尾。
- 关系仅记录有具体解释价值的关联，不生成等价或因果断言；已有关系保留。
- 这次内容补全不替代 0040 推荐质量验收及维护者长期真实使用验证。
- 来源访问条件不同：部分原文可读，部分只能读取出版方摘要、检索索引或书目。研究记录逐条说明；未取得的全文、页码与实验细节不声称已经核实。霍夫斯塔特格言的原书正文未取得，书目与引文佐证分别标明。
- 导入脚本只接受齐备的双语内容，先复制数据库并用 Registry 完整预演，再校验原库在准备期间未变化，以单个事务发布 Concept、修订和关系。新的结构化定义与出处替换旧稿中的不可靠说法，旧值仍留在修订；已有正文和图片保留，补充正文仅追加一次。
- 导入不是通用文章覆盖工具：相同稿件重复运行无变化；已存在但内容不同的补充段落需要先审阅，不自动覆盖。
