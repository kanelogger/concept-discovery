## 内容复核

依据 [0050 来源核验](0050-knowledge-samples.md)，本轮逐条对照双语字段、别名及 12 条关系。三处易误读表达重新打开原始来源核实后修正；其余来源沿用 0050 的已记录核验。本次结论均为 Agent 审阅，维护者尚未签收。

| Concept | 复核要点与结论 |
| --- | --- |
| 约束理论 | TOC 别名正确；目标是系统整体产出；没有将所有约束限定为物理瓶颈。 |
| 五步聚焦法 | 识别、挖掘、迁就、提升、重复顺序保留；与约束理论的 part_of 方向正确。 |
| 瓶颈 | 以整体流量限制界定，保留暂时排队不足以判定瓶颈的边界；与 TOC 仅用 related_to。 |
| 排队论 | 涉及到达、服务及波动；没有将 M/M/1 公式推广到任意工作流。 |
| Little 定律 | 长期平均、统一范围与单位；说明性案例 12 / 3 = 4 天不构成单项交期承诺。 |
| 在制品限制 | 将“同时进行”明确为开始后尚未完成的工作，包含等待及阻塞；补充术语表出处。 |
| 拉动系统 | 接入需要需求与可用容量；WIP 作为容量信号，未将拉动等同于简单更名。 |
| 流动效率 | 处理时间与总经过时间的口径一致；10% 的例子不等于价值或质量判断。 |
| 资源利用率 | 明确本条采用排队分析的需求/容量口径及同等服务台公式，区分实际忙碌时间占比；稳定公式不可用于超载条件。 |
| 上下文切换 | 明确讨论人的认知任务切换；任务切换别名限于此范围，未推断所有岗位固定损失比例。 |
| 批量大小 | 同时说明处理批量、移交批量及准备成本权衡，没有宣称批量越小越好。 |
| 局部优化 | 区分局部指标与整体结果，保留局部改进可能有益的边界。 |

所有案例均明确标记为原创说明性示例，没有虚构真实成效。别名未将相关方法、理论互相替代。12 条关系均有解释；其中 WIP 与流动效率、批量与流动效率、Little 定律与 WIP 的关联按编者推论标记，未声称公式能给出最优上限。Utilization Trap 继续作为情境描述，不新增正式条目。
