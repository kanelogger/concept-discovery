# 0041：合并 Concept 浏览与管理并完善卡片 CRUD

Status: ready-for-human

## 目标与范围

根据用户验收反馈改善本地 Web：移除重复的 Concept 库页，由管理视图合并目录浏览与 Concept CRUD；编辑器的领域多选使用可确认/取消的复选框弹窗，每行六项。适用当前独立 demo，不扩大原 MVP 固定票号范围 0023–0029、0031–0040。

## 验收条件

- 导航仅保留管理视图和 Dashboard；管理视图提供语言浏览、搜索、筛选、卡片/表格与详情，并承担新建、编辑、归档/恢复和受保护删除。Concept 详情不显示修订历史区块。
- 管理视图与 Dashboard 导航在顶部 header 水平居中，品牌保持左侧、语言切换保持右侧；窄屏下布局不重叠。
- 表格不展示 Version 列；点击 Concept 单元格或操作列“预览”打开完整详情弹窗，展示全部共享字段和中英文全量内容及两种语言的完整度信息。图片以中英文各一个紧凑预览组件展示；点击有图的预览可放大并在多张图片间切换。操作列只用纯文本彩色按钮，活跃条目的软删除文案为“删除”。
- 列表可见新建和行内编辑入口，草稿与归档筛选可用；中英文均可执行目录浏览与管理操作。
- 卡片和表格共用分页，每页可选 10、20、50 条；切换筛选或语言回到第一页，前后翻页边界正确。
- 管理列表的领域筛选使用与新增/编辑相同的六列多选弹窗；确认后按任一已选领域过滤，取消不改变筛选条件。
- 管理列表筛选区的领域控件不显示额外字段标签，按钮与其他筛选控件垂直对齐；编辑器领域字段标签保留。
- 卡片活跃条目显示“删除”并可恢复；归档卡片可发起永久删除，必须输入完整 Concept ID 并通过不可撤销二次确认；有引用或未归档记录不可删除。
- 编辑器中文与英文区的字段标签分别使用对应语言；领域与 Intents 都使用六列复选框弹窗，取消不改变表单，确认才回填。
- 现有 Registry 字段和验证保持不变。
