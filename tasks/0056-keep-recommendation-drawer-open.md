# 0056：点击推荐卡片后保留抽屉

Status: in_progress

## 目标与范围

用户反馈：点击推荐卡片时抽屉不能消失，只有点击“关闭推荐”按钮才能收起。保留当前关键词结果、推荐理由及现有 Concept 详情导航。

## 验收条件

- 点击推荐卡片后，抽屉继续打开，Concept 详情可读；关闭详情返回仍打开的抽屉。
- Esc 与抽屉外点击不会收起抽屉；“关闭推荐”按钮可收起。
- 既有搜索、推荐和个人库不受影响，构建、仓库检查及隔离浏览器交互通过。
