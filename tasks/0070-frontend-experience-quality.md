# 0070：前端发现体验与品质改造

Status: verification

## 目标与范围

以 Awwwards、Webby Awards、FWA 获奖作品的综合品质为参照，全面改造实际运行的 Web 产品前端。重点是让用户从模糊情境发现、理解并应用已有 Concept；不以参赛或获奖结果作为交付承诺。产品事实入口为 [产品契约](../specs/product-contract.md)。

本任务涵盖 `src/product/` 实际产品 UI、共享样式与交互、Dashboard、知识库浏览与详情、创建编辑、关系、模型设置、双语、空/加载/失败状态。`src/prototype/` 是未接入运行入口的历史原型，不纳入全站实施。概念正文、出处与结论不因视觉改造而修改；允许改写界面文案与知识呈现结构。保持本地单用户定位、双语资格、来源可追溯、修订与数据安全语义。

## 验收条件

- 发现入口成为首页主体验；关键词结果与模型推荐在同一流程中呈现。模型不可用时关键词浏览仍可用，原因和下一步清楚。
- 结果优先解释相关性、适用边界与出处；关系图只承担第二层探索。Dashboard 保留独立入口。
- 编辑按核心定义、适用边界、证据来源和关系分区，进度、未保存、冲突与失败状态明确。
- 提供两种“研究图谱”视觉处理及同一发现任务的可审阅原型，由用户选定后再扩展到全站。
- 桌面深度工作优先；手机发现、阅读、保存与基本编辑完整可用。动效服务理解，并支持减少动态效果。
- 实施阶段将 WCAG 2.2 AA、键盘操作、代表性设备性能、Chrome/Firefox/Safari 和主流手机浏览器关键流程列为硬门槛；记录可复核方法、实际结果与未覆盖范围。视觉评审由 Agent 自检和用户最终验收组成，无独立用户或同行评审。
- 行为变更配有回归价值的测试；执行相关浏览器路径、`npm run check`、`npm run demo:build`。阶段性设计/任务文档至少执行 `npm run validate`。
