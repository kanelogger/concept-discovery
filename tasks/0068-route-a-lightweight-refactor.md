# 0068 路线 A 轻量重构：去思源化预构建 SQLite 与极速阅读端

Status: ready-for-agent

## 目标与范围

按用户批准的路线 A 方案重构 Concept Discovery，彻底解决部署后访问 loading 慢、首屏体积大、后端 N+1 查思源与双容器运维笨重的问题：

- **数据层**：以 `raw/` 为唯一真相源，构建期编译产出只读 `knowledge.sqlite`（Node 24 内置 `node:sqlite` + FTS5 全文检索 + 预渲染 HTML + 预计算图谱与场景图鉴）与内容寻址静态附件 `dist/assets/`。保留 `siyuan_id` 到语义 `id` 的兼容映射。
- **服务端**：移除运行期思源内核依赖，改为单进程轻量 Node 24 服务直读 `knowledge.sqlite`，复用现有登录会话、单卡微信分享与 Agent CLI 只读接口；落地精细 `Cache-Control`、`ETag` 与 `.br`/`.gz` 预压缩，并内联首屏初始数据。
- **前端**：移除 `antd` 与 `@ant-design/icons`，基于 React 19 + esbuild（零运行时 CSS-in-JS，沿用 `paper.css` 暖纸感主题）重写轻量极速前端，按需加载精简图谱模块。
- **部署与验证**：精简为单容器 `Dockerfile` 与 `compose.yaml`，同步更新产品契约与自动化测试。

## 决策与进度

- 2026-11-26：用户批准路线 A 方案设计，开始按 4 阶段实施：
  1. 建档并核查原稿基线与 `lib/raw-format.mjs` / `server/render.mjs` 复用能力；
  2. 实现 `scripts/build-content.mjs` 与 `lib/content-store.mjs`（`knowledge.sqlite` + FTS5 + 预计算视图）；
  3. 重构轻量服务端与缓存/预压缩/首屏直出，兼容现有鉴权、分享与 CLI；
  4. 去 AntD 重构轻量前端（保留纸感主题、卡片阅读与回想、场景图鉴、按需图谱、原文资料、分享与登录），精简单容器部署并验证。
- 取舍说明：
  - 放弃线上思源内核与网页端在线编辑/归档（`database-first`、四小时批次、删除账本、Nginx 生命周期门禁），所有内容维护统一走 `raw/` + Git。
  - 前端继续使用仓库已有的 `esbuild`（零新增重型构建工具依赖）配合 React 19 + 原生 CSS 模块化 + `.br`/`.gz` 预压缩，避免额外引入 Vite 依赖树。
