## 候选与证明

1. 高置信度，移除独立双语分类表 `shared/taxonomy.json`。它在初始化时加入，提交历史与仓库静态、动态入口均无引用，且不进 npm 产物、镜像或网页构建。现行分类来自正文标签和图鉴目录，历史字段原样读回。退役一份备用分类定义，无迁移。以残留查询、原稿校验和整库回归检查。
2. 高置信度，收敛 `Knowledge.documents(kind)`。仓库唯一调用是搜索中的无参调用。初始化时加入的非概念文档查询分支无调用方，历史关系仍通过原有查询读取。将原概念查询原样用于唯一调用处，退役一个未使用的枚举接口。以 SQL 文本对比和旧卡、普通卡、补充阅读的公开搜索回归检查。
3. 高置信度，收回仅本模块调用的 `arrays`、`termMatch` 和 `assetInventory` 导出。调用图未发现模块外使用，无独立 npm 子路径契约。保留原定义及调用，收窄模块公开面。以引用搜索、整库回归检查。
4. 保留直接可运行的本地初始化入口 `bin/maintenance.mjs`。历史 0057 明确保留其入口，即使当前无仓内调用，站主仍可直接执行。删除它需要决定 CLI 退役范围。
