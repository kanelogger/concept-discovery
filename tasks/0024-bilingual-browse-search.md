# 0024：双语浏览与搜索 Concept 目录

Status: done

实施记录：2026-09-25 在独立 `codex/concept-mvp-demo` 工作区启动；依赖 0023 已完成并提交 `3e17acf`。

**Parent:** [P1 实施任务](0022-implement-concept-schema-crud-dashboard.md)

**What to build:** 用户逐语言补齐名称、描述、纯文本出处后，Concept 自动进入该语言的 Card First 浏览与搜索；卡片和表格切换使用同一结果。未齐备语言仍可在管理视图继续编辑。

**Blocked by:** [0023：持久化 Concept 草稿](0023-persist-concept-draft.md).

## Acceptance criteria

- [x] `cn` / `en` 分别编辑名称、别名、描述、标签与纯文本出处；某语言只有名称、描述及非空出处时才进入该语言浏览和搜索，另一语言不因此发布。
- [x] 出处仅检查去除首尾空白后是否非空；不解析成引用、不联网核验，空白出处仍可保存为草稿。
- [x] Web 默认中文并以卡片库为首页；当前语言卡片、详情和搜索不混用另一语言内容。无图的可浏览卡片显示占位图。
- [x] 搜索当前语言的名称、别名、描述和标签；卡片/表格视图、筛选及结果数量一致，滚动结果时筛选入口仍可操作。
- [x] 管理视图能找到当前语言的待补条目并显示缺失字段；缺少名称时以 Concept ID 标识。浏览器与服务测试覆盖单语言发布、无回退和重启后的搜索。

## 实施与证据

- `GET /api/concepts` 接受显式 `locale`、`view`、`q`、`status`、`tag`、`domain`；Web 卡片和表格使用同一响应及结果数量。普通浏览仅返回当前语言可浏览的活跃条目，管理视图包括当前语言草稿。筛选栏使用 sticky 定位，随结果滚动保持可操作。
- 隔离数据服务测试通过（2/2）：中文有非空出处时仅中文可浏览；空白英文出处保留草稿；中文别名、标签与领域筛选不命中英文，补齐英文出处后英文进入目录；重启数据库后英文搜索仍返回结果。
- Playwright 在隔离库中创建中文可浏览、英文草稿的 `browser-inversion`；中文别名搜索在卡片和表格均为 1 条。切到英文目录为 0 条且旧详情被清除；英文管理卡显示 `description, source_text`，无英文名称的另一条记录显示 ID 和 `name, description, source_text`。补齐英文描述与出处后英文目录显示 v2，英文别名搜索返回 1 条。浏览器临时数据库已删除。
- 2026-09-25：`npm run test:product`、`npm run check`、`npm run demo:build`、`git diff --check` 均通过。`npm run check` 含环境及产品测试；浏览器检查使用独立数据库，不写默认 Registry。
