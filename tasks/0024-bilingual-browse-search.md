# 0024：双语浏览与搜索 Concept 目录

Status: ready-for-agent

**Parent:** [P1 实施任务](0022-implement-concept-schema-crud-dashboard.md)

**What to build:** 用户逐语言补齐名称、描述、纯文本出处后，Concept 自动进入该语言的 Card First 浏览与搜索；卡片和表格切换使用同一结果。未齐备语言仍可在管理视图继续编辑。

**Blocked by:** [0023：持久化 Concept 草稿](0023-persist-concept-draft.md).

## Acceptance criteria

- [ ] `cn` / `en` 分别编辑名称、别名、描述、标签与纯文本出处；某语言只有名称、描述及非空出处时才进入该语言浏览和搜索，另一语言不因此发布。
- [ ] 出处仅检查去除首尾空白后是否非空；不解析成引用、不联网核验，空白出处仍可保存为草稿。
- [ ] Web 默认中文并以卡片库为首页；当前语言卡片、详情和搜索不混用另一语言内容。无图的可浏览卡片显示占位图。
- [ ] 搜索当前语言的名称、别名、描述和标签；卡片/表格视图、筛选及结果数量一致，滚动结果时筛选入口仍可操作。
- [ ] 管理视图能找到当前语言的待补条目并显示缺失字段；缺少名称时以 Concept ID 标识。浏览器与服务测试覆盖单语言发布、无回退和重启后的搜索。
