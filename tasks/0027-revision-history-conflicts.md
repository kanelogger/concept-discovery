# 0027：查看 Revision 并阻止过期编辑

Status: done

实施记录：2026-09-25 在独立 `codex/concept-mvp-demo` 工作区启动；0026 已完成并提交 `b7f4803`。服务端已有全局版本与 Revision 写入，本票完善可读历史、明确冲突恢复和端到端验收。

**Parent:** [P1 实施任务](0022-implement-concept-schema-crud-dashboard.md)

**What to build:** 管理员能在 Concept 详情中查看真实修订，区分共用字段、各语言文字、图片与 Wiki 链接的变化；两个会话编辑同一 Concept 时，较旧提交不会覆盖新版本。

**Blocked by:** [0025：维护各语言 WebP 配图与 Wiki 链接](0025-localized-image-wiki.md).

## Acceptance criteria

- [x] 修订列表显示全局版本、时间、操作与变更字段；已存在的各语言字段带 `cn` / `en` 归属，图片显示旧/新资产引用或摘要，Wiki 链接变化可追溯；新增字段沿用同一展示规则。
- [x] 从创建版本 1 起的实际变更可查看；无变化的保存不新增版本或修订，图片二进制不写入修订正文。
- [x] 编辑提交带所见版本；两个会话先后提交时，过期提交被拒绝并提示重新载入，已保存版本不受影响。
- [x] 历史修订引用的图片仍可访问；公开操作和浏览器测试覆盖当前已可编辑的文字、图片、Wiki 及并发冲突。并行切片新增的共用字段由其自身验收覆盖。

## 实施与证据

- 详情里的 Revision 可展开查看版本、时间、操作、操作者与字段路径，每个字段列出旧/新值；`locales.cn.*` 和 `locales.en.*` 保留原路径。图片引用显示哈希摘要并可打开所指资产，Revision 正文无二进制。编辑器发现 `version_conflict` 时显示明确说明和“重新载入最新版本（放弃未保存修改）”入口。
- 隔离 HTTP 测试模拟两个会话从 v1 读取：先提交文字、中文图片和 Wiki 后，旧版本提交被 409 拒绝，较新内容未被覆盖，失败媒体未写入；无变化保存维持 v2；再替换图片和 Wiki 成 v3，三个 Revision 的版本、操作、前后值和共用字段路径正确，旧/新图片仍可访问。
- 浏览器以隔离库查看 v1 创建、v2 更新，确认中英文 Wiki、共用领域、中文描述、图片哈希链接和旧新值。编辑器停留在 v2 时另一客户端写入 v3；点击保存出现冲突提示，点击重新载入后编辑器与卡片均显示 v3 的较新描述，旧输入未覆盖它。临时测试库已删除。
- 2026-09-25：`npm run test:product` 5/5、`npm run check` 31/31、`npm run demo:build` 与 `git diff --check` 均通过。
