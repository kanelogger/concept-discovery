## 目标与范围

让新会话仅通过仓库就能找到当前事实、任务进度、开发与验证入口，并如实识别尚未实现的产品能力。

交付范围为规则索引、环境命令、状态交接、产品材料差异、待办和 CI。应用框架、正式 Registry、Web UI、模型接入与业务 Skill 留到后续功能任务。

## 初始事实与保护

初始 Git 为 main，只有 README 和 LICENSE 已跟踪；`.gitignore` 与 docs 两份材料已存在但未跟踪。保留两份原稿原文，仅把与本任务直接相关的输入纳入可复现仓库；扩展已有忽略规则并保留原条目。

参考模板只作为设计输入，不成为运行时绝对路径依赖，不修改用户全局配置、相邻仓库或已安装工具。

- 主执行者：规则、环境资料、状态、任务记录及最终集成。

- 产品文档 worker：产品契约、文档索引与待办；另有只读材料审查。
- 核心取舍见 [ADR 0001](../docs/adr/0001-collaboration-bootstrap.md)。资料冲突见 [产品契约](../specs/product-contract.md)。
