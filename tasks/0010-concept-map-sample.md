# 三层概念图谱小样

Status: ready-for-human

## 目标与范围

按[图谱评估](0009-card-tree-assessment.md)制作一张小图。用真实库中已有的概念卡，选一个场景和两个学科，展示三层概念及每条关系的理由。图稿保存在本轮 Codex 可视化目录，知识库操作仅限只读。

## 决策与未决事项

场景选择「推广一种新工作方法前，试点证据够不够」。用可证伪性作为通用原则，以推论阶梯和循证实践作为中层方法，外层放两门学科的具体偏差。用确认偏误可能影响样本纳入来展示横向关联。层次和关联由本轮根据卡片内容拟定，实际使用效果待观察。
