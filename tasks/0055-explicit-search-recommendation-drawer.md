# 0055：显式搜索与推荐抽屉

Status: complete

## 目标与范围

用户要求知识库搜索输入支持清空、回车提交、搜索/重置按钮；输入变化只修改草稿。每次提交非空搜索后保留本地关键词结果，并在抽屉显示 DeepSeek 从当前语言可浏览 Concept 中选择的 0–3 条建议及理由。原 Agent 推荐资格不变，不调用真实 Key 作为自动化测试。

## 验收条件

- 输入变化不查询；回车/按钮提交搜索；清空与重置恢复未搜索结果，筛选状态明确。
- 非空提交调用独立浏览推荐接口；中文/英文候选隔离，草稿和归档排除；Agent 推荐仍遵守原资格。
- 抽屉有加载、无推荐、模型不可用、错误及推荐卡片理由状态；关闭、键盘和窄屏可用，旧请求不能覆盖新搜索。
- 合并后不损害正在使用的个人库，自动化与构建通过。

## 工作分工与进度

当前 Agent 独立负责隔离分支 `codex/search-recommendation-drawer`。主工作区服务运行中，开发在独立 worktree，不改个人数据库。

## 决策与未决事项

现有 12 条样本可浏览但不可用于 Agent 推荐；Web 发现端点使用可浏览资格，同时保留旧推荐端点语义。每次显式搜索才触发模型；清空/重置不调用模型。模型调用失败时本地精确搜索仍可用。用户已自行配置 Key，本任务不读取或复制 Key。

## 实现取舍

搜索输入维护未提交草稿，URL 的 `q` 仅代表已提交查询。每次非空提交才请求 `/api/discover`，可浏览候选与旧 `/api/recommendations` 的可推荐候选分开；响应只引用真实 Concept ID。抽屉请求随关闭或新搜索中止，避免旧结果覆盖新状态。模型失败不改变关键词结果。
