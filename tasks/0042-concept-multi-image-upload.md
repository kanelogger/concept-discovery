# 0042：支持 Concept 双语多图上传、管理与预览

Status: complete

## 目标与范围

补足 0041 管理视图验收后的图片需求：Concept 的中文与英文各自允许保存多张图片，在新增和编辑时均可上传并逐张移除；详情弹窗按语言展示缩略图组并支持图片组浏览。实现限定在独立 demo，不扩大 0023–0029 + 0031–0040 的固定 Gate。

## 验收条件

- 新建表单和编辑表单的中英文区域都可多选上传 WebP 图片；每语言没有图片数量上限。
- 编辑时可移除任意已有或新上传图片；取消编辑不改变已保存数据，保存后列表顺序与选择一致。
- 详情弹窗中中文和英文各有独立缩略图组；点击后全组放大预览，支持上一张/下一张、方向键和 Escape。
- 多图变更作为单次版本更新写入；旧单图数据兼容为只有首图的列表；修订仍保留历史图片引用，永久删除清理全部未共享的相关资产。
- `npm run check` 和 `npm run demo:build` 通过；产品 API 回归覆盖创建两语多图、编辑移除单张和历史媒体可读。

## 工作分工与进度

- 主 Agent 实施。
- 相关文件：`server/registry.mjs`、`src/product/App.tsx`、`tests/product.test.mjs`、Schema 与产品契约文档。
- 当前进度：服务端支持 `cover_images` 有序列表并保留 `cover_image` 首图兼容值；表单支持创建/编辑时多选及逐张移除，详情按语言渲染全量图片预览组。已在本地隔离数据把 `endowment-effect` 中英文都设为 2 张图。

## 决策与未决事项

- 为兼容推荐卡片与旧 Concept 消费者，保留 `cover_image` 作为 `cover_images[0]` 的派生首图；完整图片列表位于 `cover_images`。
- 图片数量不设上限；仍受 HTTP 单请求体的既有总体大小限制与 WebP 格式校验约束。
