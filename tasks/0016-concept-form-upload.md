# 0016：Concept 表单一屏布局与图片上传组件

Status: ready-for-agent

## 目标与范围

优化 Concept 新增/编辑弹窗，使常见桌面视口无需内部滚动即可完成填写；将中文图片和英文图片从 URL 文本输入改为本地图片选择组件并即时预览。图片与所有字段继续仅存在于浏览器内存，不增加后端、持久化或模型调用。

## 验收条件

- 桌面弹窗内容尽量在一屏内完整呈现，表单分区紧凑，弹窗不出现可见内部滚动条。
- 手机或较矮视口下可顺畅滚动，不裁切操作按钮，浏览器滚动条视觉上收敛。
- 中文、英文图片字段均提供图片文件选择、预览、替换和清空；仅接受图片类型，非法文件给出清晰提示。
- 上传图片以 data URL 在会话内存态预览；保存可用于 Concept 卡片和详情，刷新后按 demo 约定重置种子状态。单图限制为 8 MB，防止 demo 内存占用过大。
- 新建、编辑、取消和保存工作正常；npm run demo:build 与 npm run validate 通过。
- 不改变 Concept 字段语义；仅替换图片输入交互。

## 工作分工与进度

- 负责人：主 Agent；仅负责 demo 表单、弹窗样式、任务记录。
- 进度：completed；用户明确要求弹窗无滚动条且优先一屏展示，并要求图片改用上传组件。

## 决策与未决事项

- 上传仅走浏览器文件选择，不提供 URL 文本字段或服务器上传。
- 采用 FileReader data URL 预览图片，避免弹窗取消或替换操作影响已保存的本地预览；刷新后模拟数据恢复种子状态。
- 宽视口双语区并排，窄视口堆叠；窄视口允许滚动并隐藏滚动条视觉，不隐藏可滚动能力。
