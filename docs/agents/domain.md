# Domain Docs

Before domain work, read the root `AGENTS.md`, `workflow-state.json` and its task file when present, plus relevant `specs/` and `docs/adr/` entries.

Use `specs/product-contract.md` as the product contract and relevant files under `docs/` as supporting material. Follow `workflow/README.md` and `workflow/task-template.md` for task records. Record durable shared terminology in `CONTEXT.md` when the product contract needs a separate glossary.

Use established project terminology. Surface conflicts with existing ADRs and product contract rather than silently overwriting them. This is a single-project repository.
