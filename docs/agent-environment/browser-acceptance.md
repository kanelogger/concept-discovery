# 桌面浏览器验收

日常使用 ego-lite。先运行 `npm run test:ego -- start`，再阅读 `ego-browser skill`，创建本轮唯一 TaskSpace，通过真实控件完成六组检查点，按当前[验证规则](../../rules/testing.md)记录截图、snapshot和CLI/API读回。预览、输入、点击及图片上传均走真实界面。

覆盖明亮双栏的1280/1440、键盘焦点、长标题/代码/链接、空/错误/未保存状态，系统深色仍明亮。普通知识卡和Agent追加可编辑；旧卡或复杂布局说明只读原因。正文图片、来源、自测及补充阅读保留。

关键竞态与故障由 `npm run test:browser` 的显式白名单承担。真实用户流程不靠测试替身、隐藏字段或接口写入代替。独立审阅先核对持久化数据和结论，再审代码。清理指定栈和本轮浏览器空间后核验记录，真实库不参与测试。
