## 对新目标的影响

1. 现有首页的第一动作是浏览或维护目录。已确认的新目标要求把“描述情境→发现概念”提升到首页，原知识库与 Dashboard 转入清楚的后续入口。
2. 当前卡片空间优先给无图占位和元数据。新结果应优先展示相关原因、适用边界与出处，再让用户探索关系；图片缺失时不应形成大面积空白。
3. 当前详情保留可靠的字段降级阅读。新呈现需要把定义、适用情境、边界和来源组织成可快速判断的阅读顺序，并保留文章与字段的真实状态。
4. 当前编辑字段多且跨双语。分区设计必须保留原有资格、保存、冲突与修订语义，不把视觉进度误报为内容已审核。
5. 搜索提交自动打开推荐抽屉是现行需求规定，并非实现缺陷；用户已明确授权改为关键词与 AI 结果合流。实施时须同步产品设计文档、相关测试和导航状态。
