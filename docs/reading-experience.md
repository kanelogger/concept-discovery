# 个人知识卡使用与托管

网页以卡片列表、搜索和单篇正文为主。新建时填写标题，正文用自己的语言整理理解、出处、边界、例子和相关链接；自测问题直接作为普通文字写入。搜索接受标题、原文词语或任务线索，命中补充阅读时返回所属卡片。Agent适用性分析在明确要求后进行。

编辑提供 Markdown、预览、图片插入、保存与取消。图片宽度可持久化，单独调整高度会在重开时恢复。离开前注意保存状态；冲突或结果未知时保留草稿并先核对操作。早期固定字段卡和无法保真编辑的原生结构标为只读，可请Agent按块维护。相关文档链接可正常打开，也可使用浏览器前进/后退和新标签页。

页面使用纸感样式。正文为 17px，图片、来源、相关链接、旧关系与自测文字保留。键盘焦点清晰，减少动效跟随系统。

## 服务与备份

默认应用仅绑定127.0.0.1:6806；公网部署时由自己的HTTPS反向代理接入应用，配置service.json的publicUrl为外部HTTPS源地址，内核端口不发布。用户只有一个访问码，Agent使用另一枚令牌；不配置厂商云同步或订阅。反向代理需保留请求Origin并转发附件上传，不能把内核API暴露公网。

备份应覆盖私有配置目录内workspace和operations及凭据；停止写入或停止Compose后取得一致性备份，保存到受保护位置。整篇/块修改的操作恢复不等于完整工作区灾备；恢复整份工作区应先停止服务、恢复到新目录并核对库身份，禁止直接覆盖运行中的资料。

初始化拒绝覆盖已有目录。旧SQLite、self-use工作副本及迁移归档均为真实资料。验收使用独立样本库。具体启动命令见[命令说明](agent-environment/commands.md)。
