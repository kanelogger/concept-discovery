# 个人知识卡使用与托管

先从列表关键词或标签找卡，详情阅读正文、来源和补充阅读。编辑使用Markdown源码和安全预览，图片、链接、代码和表格保留。写理解进入同一编辑器；有问题时可以先回想再展开参考解释。

“资料与整理”保存实际提供的原文，显示模型和目的地后显式生成单张草稿。选新卡或一张已有可编辑卡；生成不写卡，用户在普通编辑器审阅后保存。已有正文和理解保留，草稿追加后可人工合并。旧来源链接、提案和记录只读可查。

未保存输入仅在当前标签页内存保留。401重新登录继续，版本冲突重读，未知保存先核对operation-status原回执。旧固定字段卡与复杂布局保持只读整篇，可由Agent按块维护。

## 服务与备份

默认仅绑定127.0.0.1:6806；远端由HTTPS反向代理接入，service.json的publicUrl设为外部源。内核仅容器内可达，网页访问码、Agent Token、内核Token各自独立。

暂停写入或停止Compose后备份workspace、operations、wiki及必要配置/凭据。只恢复部分目录会遗漏内容或引用。整库恢复使用新目录并核对库身份，不能覆盖运行中的资料。历史来源、提案、事件和理解不因功能精简删除。

检查按改动风险执行，真实测试使用隔离样本。见[命令](agent-environment/commands.md)和[验证规则](../rules/testing.md)。
