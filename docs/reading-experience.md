# 个人知识卡使用与托管

「知识卡」按关键词、标签或更新日期筛选。打开卡片后可跳到正文小节，阅读出处和补充阅读。遇到自测问题，点「试着回想」，想好后展开理解与参考。旧的新增卡片书签会打开列表，旧的编辑书签会打开对应卡片的阅读页。

「场景」可按问题或学科翻阅卡堆。「图谱」可查看卡间引用并定位原句。从卡片详情返回，继续刚才的图鉴或图谱位置。

在「资料」中按标题查找原始快照，查看正文、作者和出处。卡片中的 `/wiki?source=<快照ID>` 链接直接打开对应原文。切换原文后可用浏览器前进、后退；展开「历史整理提案」可核对归档提案及引用。

## 维护知识

在本地 `raw/` 编辑知识卡、图鉴目录与材料。自己的理解写进卡片正文，图片、原文或补充阅读放在 `assets/`。在仓库根目录运行 `npm run raw -- check` 校验，目标库启动后用 `npm run raw -- sync --dry-run` 核对差异，再运行 `npm run raw -- sync` 写入并读回。[原稿格式与示例](../raw/README.md) · [同步、归档与回执恢复](agent-environment/commands.md#本地知识原稿)

## 服务与备份

应用默认仅绑定 `127.0.0.1:6806`。显式本机模式可直接打开网页。远端由 HTTPS 反向代理接入应用内登录，`service.json` 的 `publicUrl` 设为外部源。内核仅在容器网络内可达。Agent 通过独立令牌执行只读命令。应用的 `GET /api/status` 返回 `data.readOnly: true`。[站主开通与恢复](agent-environment/commands.md#开通和恢复站主)

暂停写入或停止 Compose 后，整体备份私有根，包括 workspace、operations、wiki、实例首次同步后生成的 raw-sync，以及必要的配置、凭据和认证库。整库恢复使用新目录并核对库身份与挂载，开放访问前[撤销备份中的网页会话和分享链接](agent-environment/commands.md#开通和恢复站主)。Git 中的 raw 原稿可重建知识卡、附件、原文和库内引用；还原原实例的外部书签、操作回执和同步基线需要完整冷备。

检查按改动风险执行，真实测试使用隔离样本。见[命令](agent-environment/commands.md)和[验证规则](../rules/testing.md)。
