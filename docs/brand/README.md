## 使用

- 网站页头和登录页使用32×32px；favicon可缩至16px。正文或对外材料推荐至少24px。
- 图形外保留至少图形宽度的1/8空白；与名称之间建议10px，长宽等比缩放。
- 名称写作 `Concept Discovery`。网站使用现有系统字体与600字重，避免新增字体下载。
- 图形与文字同时出现时，图形使用空alt，链接名称由文字提供；单独作为按钮/链接时提供描述用途的可访问名称。
- 不将概念稿中的展示编号、背景板和生成文字用作Logo，不拉伸、旋转或加渐变。

网站复用公开的 `/favicon.svg` 路径，无新增静态服务路由。单色与反白版是可下载的仓库资产，不随页面额外加载。
