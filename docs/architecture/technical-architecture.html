本机和远程入口

本机模式经回环直连应用。远程模式经 Nginx 进入，私有页面使用站主会话，Agent CLI 使用独立只读令牌。

数据持久化

私有根还保存 operations/ 操作回执与备份，以及 raw-sync/ 实例绑定与修订基线。受管任务队列和账本检查点保存在冷备之外。

两条维护入口

普通本机用 raw CLI 校验原稿、经临时容器写入并读回。受管实例由宿主维护进程串行写入。删除候选由独立 GitHub 工作流验证后才能发布到权威账本。
