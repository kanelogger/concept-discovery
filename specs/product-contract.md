# 当前产品契约

Concept Discovery 是中文单人桌面知识卡网站。网页用于阅读、搜索、回想和核对原文。知识卡、附件和原始资料通过仓库的 `raw/` 维护。Agent 在明确要求时查询、应用概念或修改原稿。

仓库中的本地原稿按「总览 → 学科导读 → 知识卡」组织，每张卡使用 YAML 元数据、Markdown 正文和相对路径附件。本地命令能离线校验原稿。同步时将显式 Wiki 引用或卡片文件链接转换为目标库的文档链接，保存出处、附件和补充阅读。原库使用既有身份及修订保护，空库分配文档身份后解析相互引用。网页从思源知识库读取，库中独立编辑会在同步时报告冲突。[原稿格式](../raw/README.md) · [命令与恢复](../docs/agent-environment/commands.md#本地知识原稿)

## 卡片阅读

React/Ant Design 网页提供「知识卡」「场景」「图谱」「资料」四个入口。卡片列表按关键词、标签和单日更新日期筛选，每页 20 条。搜索覆盖标题、正文和补充阅读。返回列表保留筛选与阅读位置。旧日期范围链接继续生效，旧 `/cards/new` 书签跳到列表，`/cards/<ID>/edit` 跳到对应详情，并沿用原有筛选和正文锚点。

普通列表先显示当页卡片及其标签。展开标签选择器时读取符合当前关键词和日期的全部标签。当前标签页从详情返回时，若最近一次成功读取的筛选条件和页码吻合，先恢复该页并在后台核对。核对期间可以继续筛选和翻页。

在本地 Markdown 中写适用情境、来源、边界、例子、自测和自己的理解。网页能展示普通卡、旧固定字段卡和既有补充阅读。展示时将思源相对附件地址 `assets/…` 转为 `/assets/…`，原稿中的图片、引用和链接保留。

知识卡默认进入阅读态，按名称、别名、标签、理解、适用情境、其余正文排列。只有已有非空别名时才显示别名。标签沿用列表的 Tag。已有别名、理解和适用情境小节只调整展示顺序，保留原 Markdown 和锚点。可导航的小节不少于三个时，桌面目录位于正文右侧并标记当前小节，其余卡片居中。有问题的卡片提供「试着回想」，进入后保留名称、别名、标签和适用情境，折叠理解和参考正文，读者可展开答案或返回阅读。块链接进入阅读态并定位。

## 知识图谱

导航的「图谱」打开 `/graph`。全库卡片的范围与未筛选列表相同，保留没有引用的卡。D3 力导画布按卡片的第一个显式学科分区。没有学科时使用正文「标签」中的第一个普通标签，其余归入「未分类」。节点大小取决于有多少张不同的卡引用它。最高入链数低于 8 时，首屏标签和核心节点的门槛按当前库的最高入链数调整；「只看核心」显示具体条件。同一分类的节点共享颜色和轮廓；连线只来自正文里的显式引用。多个出处合并到同一条有向边，反向的引用单独成边。图鉴目录的收录清单、共同学科和共同标签均不产生卡间连线。

固定左栏提供搜索、分类开关、关系标签、只看核心、重置视图及卡片详情，余宽用于图谱画布。悬停显示提示并高亮直接相连的节点和边，单击节点打开跟随它的浮卡，双击另开知识卡。回车搜索居中定位，滚轮缩放，拖空白平移，拖节点可调整布局。浮卡可以转读邻卡或逐处打开引用原句。来源位置变化时，阅读器打开来源卡并提示。从原文返回可恢复选边、出处与镜头。浏览器后退、前进支持图内回走。同源 `GET /api/graph` 只读计算图谱，部分读取失败时显示已扫描范围并提供重试。[图谱实现依据](https://github.com/yibie/claude-best-practices-zh/blob/37648288e962ad9e88c54086d4d55f3f46862b69/mindmap/graph.html)

从详情返回图谱时，当前标签页先恢复最近一次完整读取的图谱、镜头和选择，再核对当前库。核对失败会提示重试。有部分正文未读到时会显示扫描范围。筛选分类和核心节点沿用当前节点布局。

## 场景图鉴

导航的「场景」打开 `/scenarios`。首次按问题场景浏览，条目收起，也可切换到按学科。两个视图的类目导航保持可见。展开条目后可按卡名跳转，也可在卡堆中左右滑动、点击卡片两侧或按方向键。从详情返回恢复原视图、卡片与阅读位置。同一浏览器回访时恢复最近的分类、展开项、卡片和滚动位置，显式类目链接仍定位到指定类目。

从问题场景可沿卡片的「所属学科」跳到对应学科，从学科可沿「相关问题场景」跳到具体问题。卡堆及从图鉴打开的详情使用同一份分类索引，跳转时选中同一张卡。返回原处会恢复出发时的卡片、滚动位置和入口焦点。

问题场景由当前库内唯一一张标题为「场景图鉴」的普通卡策展。用 `##` 写类目、`###` 写场景问题，可紧跟一段适用说明，再按需要排列卡片链接。在问题前加 `【精选】` 可显示推荐标记，标记不影响场景定位。在目录原稿中列出目标卡的 Markdown 相对链接，或沿用同一实例内的 `- [卡片标题](/cards/文档ID)`。需要场景专属说明时，在链接后追加 ` — 用途`。卡片显示当前标题。重复目录或无效链接会在问题场景视图提示，仍可按学科浏览。缺少目录时可直接按学科浏览。要调整问题场景或学科顺序，在本地维护目录卡的 `article.md`，再同步到目标库。

按学科从「标签」小节的 `学科：学科名`（或半角冒号）读取卡片归属。一张卡可属于多个学科，也可进入多个场景。目录卡可在保留标题 `## 学科目录` 后直接写一组纯文字学科名称，每项一行，如 `- 心理学`。学科视图按该列表顺序展示，保留空学科，按名称匹配标签。没有有效列表时，仍从已有标签生成学科。「学科目录」用于定义顺序与名称，场景视图会跳过此节。图鉴由同一知识库只读计算，网页通过同源 `GET /api/scenarios` 读取索引、卡片摘要和目录诊断。

## 原文与历史阅读

「资料」打开 `/wiki`，可按标题搜索已保存的原文快照。选中后显示原文全文、可用的作者、出处链接和版本，URL 指向 `/wiki?source=<快照ID>`。从卡片可直达对应版本，浏览器前进和后退恢复相应原文。展开「历史整理提案」可读取归档的条目、理由和引用，历史知识事件由只读 CLI 提供。

实际提供的 UTF-8 文本或 Markdown 通过本地原稿保存。原文最多 200000 个 Unicode 字符且不超过 1 MiB，超限会报错。出处 URL 作为元信息。修改原文后，同步创建独立快照，原有快照和链接继续可读。[知识规则](wiki-content.md)

## 应用接口与写保护

网页与 Node CLI 共用只读命令，包括 `list`、`search`、`get`、`get-document`、`sources-list`、`source-get`、`wiki-card`、`wiki-proposals`、`wiki-proposal`、`wiki-events`。公开 `get-document` 返回 `editable: false`、`deletable: false`，并在 `question` 提供同一版正文的自测问题，无自测时为空字符串。网页直接从详情读取该字段。`wiki-card` 继续返回 `{id, revision, question}`。知识图谱、场景图鉴和附件各有只读 GET 入口。CLI 从 stdin 接收 JSON，成功时 stdout 输出 `{ok:true,data}`，错误写入 stderr 并非零退出。

查询命令对同源浏览器和有效 Agent 令牌使用相同的只读白名单。公开接口拒绝正文编辑、上传、导入资料、生成草稿、模型设置和历史写入命令。只读查询既有资料时，缺少的归档目录按空库处理。

单独启用宿主维护的 HTTPS 实例提供站主归档列表 `/archives`。有站主会话的主卡可预览并归档。归档列表可预览恢复、补记旧归档标记或彻底删除，后一项需要站主复核密码。维护任务绑定确认时的原稿和实例，归档后常规阅读与搜索隐藏目标，恢复时复用已核实的实例文档 ID。彻底删除须先核实原稿和线上归属，向 Git 权威账本追加不可逆决定，再清理并读回目标线上副本。共享附件在原稿迁移后继续供保留卡使用。已有 Git 历史和离线冷备保留。恢复副本经门禁核对权威账本及逐卡在线结果后开放访问。[维护与冷备](../docs/agent-environment/commands.md#站主卡片维护与冷备门禁)

维护设置为 `dataFlow: "database-first"` 时，站主新增、编辑、归档和恢复主卡先写入思源。常规原稿变更在北京时间每四小时的批次更新 `raw/` 并快进 Git。页面显示待同步数量、冲突及下次批次。同一实例凭已核实的归档回执恢复原文档 ID；仅有 Git 归档时，在新实例创建主卡并重新解析引用。

站主确认彻底删除后，网站立即隐藏该卡并暂停分享。存在待删除原稿时，站主页面右上角显示提醒。点击可逐卡查看已核实的原稿路径并复制本地命令。站主在项目仓库运行命令，核对暂存差异后自行提交并推送。命令会保留共享附件及其引用。网站从远端 `main` 核实原稿已移除后清除提醒。线上彻底删除另须在到期批次核实权威决定、清除线上副本并读回。撤销待删需要再次验证站主密码；已签入的删除决定按原操作继续完成，站主自行提交的原稿变更由站主管理。[数据库优先批次与手动验收](../docs/agent-environment/commands.md#站主卡片维护与冷备门禁)

使用 Git 优先维护时，日常写作、调整目录及归档通过本地原稿命令完成。同步核对所选实例、文档身份和修订，保存冻结的变更计划，写后读回。已绑定的文档如被独立改动，先核对冲突。需要核实或恢复一次已有操作时，使用本地 `npm run raw -- status` 或 `npm run raw -- recover`，按原回执及写后修订核对。整篇保存、旧卡转换和整篇恢复还核对原生块签名，保护修订号未体现的子块修改。完整参数、续跑和结算流程见[命令说明](../docs/agent-environment/commands.md#本地知识原稿)。

## 运行与验证

Node 24.7 及以上的 24.x 应用和固定的思源 3.8.9 内核经 Compose 运行，仅发布应用端口，默认 `127.0.0.1:6806`。显式 `local` 模式只允许回环公开源，可直接打开网页。远端通过 HTTPS 代理进入 `required` 模式，站主使用用户名和密码登录。私有页面、数据及附件需要有效浏览器会话，Agent 令牌单独用于只读命令。浏览器写请求需匹配配置的 Origin。跨源 API/附件请求及不匹配的主机名会被拒绝。`GET /api/status` 保留 `data.readOnly: true` 的健康探针契约。

未登录时打开书签，登录成功后恢复站内阅读地址。浏览器会话最长 24 小时，由服务端核验和撤销。站主通过目标宿主的管理命令开通账户、改密或撤销会话，改密同步撤销旧会话。 [维护命令](../docs/agent-environment/commands.md#开通和恢复站主)

认证模式下，站主可为一张主知识卡创建、复制或撤销一条有效分享链接。持有链接的人可免登录阅读创建时的标题、正文和可读取的本地正文位图，位图最多归集 48 个资源并限制在 6 MiB 内。站内链接保留文字，补充阅读和原附件地址仍需登录。分享不缓存、不建立登录会话。原卡归档期间无法打开分享，撤销后原链接永久失效。分享后的编辑不传播到已有副本，更新分享时先撤销再创建。

站主创建分享时使用按原稿批量生成的转发标题、摘要和 PNG 封面。无匹配素材的卡片使用卡片标题和站点封面。分享前的预览仅供站主查看。旧链接继续打开正文，一键启用新版转发预览后可以复制具有独立预览地址的新链接。公开预览仅包含发布的分享素材，正文仍凭片段中的随机凭证读取。撤销和归档同时关闭本站预览及对应封面。启用公众号配置后，微信公众号网页分享为好友会话设置标题、摘要、封面，为朋友圈设置标题和封面。 [公众号配置](../docs/agent-environment/commands.md#配置微信转发样式)

`deploy:init` 只初始化全新私有目录。首次启动创建知识库根与关系归档，项目原稿须另行显式同步。已有实例启动时沿用原数据和身份。卡片、理解与附件位于 `workspace/`，原文及历史提案与事件位于 `wiki/`，操作回执与备份位于 `operations/`，实例同步基线位于 `raw-sync/`。恢复原实例的身份、书签和完整历史使用完整冷备。[服务与备份](../docs/reading-experience.md#服务与备份)

网页仅提供中文。卡片查询拒绝 `locale`、`language`、`locales` 参数。旧 schema 1 卡保留中文固定字段，旧补充阅读以及稳定块链接继续可读。验证按影响范围选择，当前能力与未覆盖项见[验证规则](../rules/testing.md)。
