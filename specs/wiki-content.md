# 知识内容与原文

知识库使用中文。技术名称、代码、引文与出处沿用原文。维护位置为仓库的 `raw/`，网页和日常 CLI 读取同一思源知识库。

## 知识卡

每张卡有一份带 YAML 元数据的 `article.md`。标题来自 `name`，自己的理解、自测问题、适用情境、边界和相关引用写在正文。阅读器按内容安排展示顺序，保留原有理解和章节锚点。有自测问题时，读者可以先回想，再展开参考描述。

卡间引用写在说明关系的句子里，目标可用 Wiki 标识或相对文件链接。图片、原文与补充阅读放在相应卡片的 `assets/`。图鉴目录的收录和学科归属用于导航。[卡片格式与示例](../raw/README.md)

## 来源与快照

`sources` 列出实际提供的原文文件。没有关联卡片的材料可作为 `kind: source` 原稿独立保存。出处 URL 只作来源标记。同步逐份检查原文，单份最多 200000 个 Unicode 字符且不超过 1 MiB，超限报错。内容改变时建立独立快照，保留旧版本与引用。卡片旁的出处链接和 `/wiki?source=<快照ID>` 均可供读者核对实际文本。

资料页可按标题查找原文、阅读全文和历史整理提案。`sources-list` 与 `source-get` 读取来源，`wiki-card` 读取卡片的自测问题。`wiki-proposals`、`wiki-proposal`、`wiki-events` 提供归档读取。既有整理区、人的理解和旧卡正文保存在原文档中。

## 维护与恢复

在原稿中修改后，离线检查并预览目标库差异，再通过本地同步写入并读回。网站访问和日常 Agent 令牌仅提供读取能力。原文和历史记录按库身份保存在私有根的 `wiki/`，卡片与附件在 `workspace/`，操作回执在 `operations/`，实例绑定与未完成批次在 `raw-sync/`。恢复原实例时整体还原私有根及必要凭据。[同步与回执恢复](../docs/agent-environment/commands.md#本地知识原稿)
